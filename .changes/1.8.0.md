## 1.8.0 - 2026-08-24
### Added
* Added support for the Cf-Ray header
### Changed
* The parameters `fs.ttl`, `server.shutdownTimeout`, and `server.throttle.backlogTimeout` are now of type `time.Duraction`.
* The `service` parameter now appears in all logs
### Removed
* The setting to enable HTTP/2 has been removed. It now follows the default behavior of Go's `net/http`.
* Logging of logger synchronization errors has been removed
* The warning about not using the cache has been removed
### Fixed
* Fixed a panic caused by a nil pointer dereference when shutting down a server with no cache.
