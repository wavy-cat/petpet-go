## 1.7.0 - 2026-06-14
### Added
* Support for WebP for custom uploads
### Changed
* Updated Go to 1.26.4
* Make Discord and Custom Upload optional
* Make server timeouts configurable
* Reuse a shared HTTP client for Discord requests
### Removed
* Custom proxy configuration
### Fixed
* Correct proxy settings usage
